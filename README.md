# 사그라다 파밀리아 온라인

브라우저로 접속해 여러 사람이 함께 3D 사그라다 파밀리아를 걷는 웹 서비스입니다. 설치와 가입이 필요 없습니다.

- 3D: Three.js (r147, CDN). 탑 18개, 탄생·수난·영광 파사드, 내부의 나무 기둥, 시간대 전환
- 실시간: Node.js + `ws` WebSocket 서버 하나
- 순례 모드: 바닥 클릭이나 WASD로 이동, 합장, 초 밝히기 (초는 서버에 10분 동안 남아 늦게 온 사람에게도 보임)
- 채널: 한 채널에 최대 50명. 차면 다음 채널로 자동 배정 (`?ch=3`처럼 직접 고를 수도 있음)

## 로컬 실행

```bash
npm install
npm start          # http://localhost:3000
```

같은 와이파이의 다른 기기에서는 `http://<내 PC IP>:3000`으로 들어오면 됩니다.

## 배포 (누구나 주소로 접속)

WebSocket을 지원하는 Node 호스팅이면 어디든 됩니다.

**Render.com (무료 플랜 가능)**
1. 이 폴더를 GitHub 저장소로 올립니다.
2. Render → New → Web Service → 저장소 선택
3. Build Command `npm install`, Start Command `npm start`
4. 배포가 끝나면 `https://<이름>.onrender.com`이 접속 주소입니다.

무료 플랜은 15분 동안 아무도 없으면 잠들고, 첫 접속 때 30초쯤 깨어나는 시간이 걸립니다.

Railway, Fly.io, 개인 VPS도 같은 방식입니다. 서버는 `PORT` 환경 변수를 따릅니다.

## 환경 변수

| 이름 | 기본값 | 뜻 |
|---|---|---|
| `PORT` | 3000 | 서버 포트 |
| `CHANNEL_CAP` | 50 | 채널당 최대 인원 |
| `MAX_CHANNELS` | 100 | 채널 개수 |

## 구조

```
server.js          정적 페이지 + /ws WebSocket + /healthz 상태 확인
public/index.html  3D 화면과 클라이언트 전체
```

메시지는 JSON입니다. 클라이언트는 `hello`(입장), `presence`(위치·방향·합장), `event`(초)를 보내고, 서버는 `welcome`, `presence`, `leave`, `event`를 같은 채널에 중계합니다. 서버는 허용된 필드(이름 16자, 색, 좌표, 방향, 합장)만 통과시키고, 초당 메시지 수와 초 밝히기 간격(1.5초)을 제한합니다.

## 알아 둘 점

- 상태는 서버 메모리에만 있어서, 서버가 재시작하면 켜 둔 초가 사라집니다.
- 채팅은 일부러 넣지 않았습니다. 넣으려면 욕설 필터와 신고 기능을 같이 고려해야 합니다.
- 벽과 탑에는 충돌 판정이 없습니다.
